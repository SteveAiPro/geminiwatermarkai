## 🔬 Mathematical Principle: Reverse Alpha Blending (去水印核心数学原理)

Unlike traditional generative AI inpainting methods (which erase the area and "hallucinate" synthetic pixels, frequently leaving blurry smears or distorted textures), this tool uses **Mathematically Exact Reverse Alpha Blending**.

### 1. The Watermark Stamping Equation (正向透明度混合公式)
When Google Gemini places a visible watermark over the generated background, it blends the original background pixel $P_{\text{original}}$ with the pure white watermark pixel ($L = 255$) using an alpha transparency map $\alpha(x, y) \in [0, 1]$:

$$P_{\text{watermarked}} = (1 - \alpha) \cdot P_{\text{original}} + \alpha \cdot L$$

Where:
- $P_{\text{watermarked}}$ is the pixel value observed in the downloaded Gemini image.
- $P_{\text{original}}$ is the true pristine pixel generated by the diffusion model.
- $\alpha$ is the transparency opacity of the watermark mask at coordinate $(x, y)$.
- $L = 255$ represents the pure white watermark color value.

### 2. The Inverse Reconstruction Equation (逆向数学还原公式)
Because the watermark is an additive linear alpha blend, we can mathematically solve for the exact original pixel without any guesswork:

$$P_{\text{original}} = \frac{P_{\text{watermarked}} - \alpha \cdot 255}{1 - \alpha}$$

By pre-extracting Google's exact multi-scale 48px and 96px alpha channel transparency profiles ($\alpha$-maps), we apply this inverse formula to each RGB channel ($R, G, B$) individually. The watermark is **completely cancelled out**, restoring the underlying high-frequency textures with 100% mathematical fidelity!

### 3. Multi-Scale Normalized Cross-Correlation (NCC) Auto-Detection
Google Gemini uses several placement conventions depending on image aspect ratio and version:
- **Gemini & Nano Banana Adaptive Inset (12.5% Inset)**: positioned at $192 \times \frac{\min(W, H)}{1536}$ px from the corner.
- **Classic Corner Adaptive (4.16% Margin)**: positioned at $64 \times \frac{\min(W, H)}{1536}$ px from the edge.
- **Fixed 96px Inset / Fixed 96px Classic**: static 96px badge.

Our engine runs a multi-scale search pyramid ($0.55\times$ to $1.70\times$) using **Normalized Cross-Correlation (NCC)** combined with **gradient magnitude edge matching**:

$$\text{NCC} = \frac{\sum (I - \bar{I})(T - \bar{T})}{\sqrt{\sum (I - \bar{I})^2 \cdot \sum (T - \bar{T})^2}}$$

This automatically locks onto the watermark's exact sub-pixel coordinates $(x, y)$ and scale within 5ms. An optional interactive **Fine-Tuner Console** is also provided for custom-cropped images.

## 🚀 Quick Start / Local Development (本地运行)

### Prerequisites
- Node.js 18.x or 20.x+
- npm or pnpm or yarn

### Installation
```bash
# 1. Clone repository
git clone https://github.com/SteveAiPro/geminiwatermarkai.git
cd geminiwatermarkai

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to test the tool locally.

### Production Build
```bash
npm run build
npm run start
```
